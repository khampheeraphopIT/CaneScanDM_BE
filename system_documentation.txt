================================================================================
รายงานสรุปคุณลักษณะและคู่มือการใช้งานระบบ Sugarcane Disease Detection (CaneScan)
================================================================================

เอกสารฉบับนี้รวบรวมข้อมูลเทคนิคเชิงลึก ฟีเจอร์ และคู่มือการติดตั้ง/ใช้งานฉบับสมบูรณ์
เพื่อให้คุณสามารถเทรน ดูแล และใช้งานระบบได้อย่างครบถ้วน

--------------------------------------------------------------------------------
1. คุณลักษณะและเทคนิคเด่น (Features & Techniques)
--------------------------------------------------------------------------------

🧠 สถาปัตยกรรมโมเดล (Model Architecture)
- Deep Learning Backbone: ใช้ ResNet50 ซึ่งมีประสิทธิภาพสูงในการแยกแยะรายละเอียดเล็กๆ บนใบอ้อย
- Hybrid Neural Network: รวมข้อมูล "รูปภาพ" และ "ข้อมูลตัวเลข" (สภาพอากาศ + ดัชนีพืช) เข้าด้วยกัน
- Custom Head: เพิ่มชั้น BatchNorm1d และ Dropout เพื่อความเสถียรและป้องกันการทายจำกัดแค่ในฐานข้อมูลเดิม

🖼️ เทคนิคการจัดการภาพ (Image Processing)
- High Resolution (224x224): ขยายขนาดภาพเพื่อให้เห็นขอบบาดแผลของโรคชัดเจนขึ้น
- Texture Enhancement (CLAHE): ดึงความคมชัดและลายเส้นของโรคออกมา แม้แสงจะไม่เอื้ออำนวย
- Multi-scale Robustness: ระบบถูกฝึกให้รู้จักใบอ้อยทั้งแบบ "ถ่ายใกล้" และ "ถ่ายไกล"

📊 วิศวกรรมฟีเจอร์ (Feature Engineering)
- ระบบดึงฟีเจอร์อัตโนมัติ 8 อย่าง: VARI, ExG, CIVE (ดัชนีพืช), GLCM (วิเคราะห์ผิวสัมผัส 3 ค่า), LBP (รูปแบบจุดพิกเซล), และ Edge Density (ความหนาแน่นบาดแผล)

--------------------------------------------------------------------------------
2. ขั้นตอนการติดตั้ง (Installation Guide)
--------------------------------------------------------------------------------

1. ติดตั้ง Python (แนะนำเวอร์ชัน 3.9 ขึ้นไป)
2. ติดตั้ง Library ทั้งหมดที่จำเป็น:
   เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วพิมพ์:
   pip install -r requirements.txt

3. การตั้งค่า API Key (OpenWeather):
   - สร้างไฟล์ชื่อ .env ไว้ที่โฟลเดอร์หลัก (Root)
   - ใส่ข้อมูลดังนี้:
     OPENWEATHER_API_KEY=ใส่คีย์ของคุณที่นี่
     PORT=8000

--------------------------------------------------------------------------------
3. การเทรนโมเดลใหม่ (Training Guide)
--------------------------------------------------------------------------------

สำคัญ: เนื่องจากการอัปเกรดสถาปัตยกรรมใหม่ คุณต้องรันการเทรน 1 ครั้งเพื่อให้ได้ไฟล์สมองใหม่

วิธีรัน:
พิมพ์คำสั่งนี้ใน Terminal:
python -m src.model.model

สิ่งที่ระบบจะทำตอนเทรน:
1. วิเคราะห์ภาพทั้งหมดใน Dataset และดึงฟีเจอร์
2. สร้างไฟล์ 'model/scaler.joblib' (ใช้ปรับสเกลข้อมูลสภาพอากาศ)
3. สร้างไฟล์ 'model/best_model.pth' (ตัวโมเดล ResNet50 ที่เก่งที่สุด)

--------------------------------------------------------------------------------
4. การเริ่มใช้งานระบบ (Running the Server)
--------------------------------------------------------------------------------

เมื่อมีไฟล์โมเดลแล้ว ให้รัน Backend ด้วยคำสั่ง:
python main.py

ระบบจะทำงานที่ http://localhost:8000 (หรือตาม Port ที่คุณตั้งไว้)

--------------------------------------------------------------------------------
5. วิธีการทดสอบ API (Testing)
--------------------------------------------------------------------------------

คุณสามารถใช้ Postman หรือโค้ดหน้าบ้านส่งภาพเข้ามาที่:
URL: POST http://localhost:8000/predict

ข้อมูลที่ต้องส่ง (Form-data):
- files: (อัปโหลดรูปภาพใบอ้อย - สามารถเลือกส่งได้ทีละหลายรูป)
- province: (ใส่ชื่อจังหวัดภาษาไทย เช่น "ลพบุรี")

--------------------------------------------------------------------------------
6. ขั้นตอนการจัดเก็บข้อมูลและบันทึกผล (Logging)
--------------------------------------------------------------------------------

- ทุกภาพที่อัปโหลดจะถูกเก็บไว้ที่: uploads/ (พร้อมชื่อไฟล์ที่ระบุเวลาที่ถ่าย)
- ทุกผลการทำนายจะถูกบันทึกที่: prediction_logs.csv (ใช้สำหรับทำรายงานย้อนหลัง)
- หากภาพไหนไม่ใช่ใบอ้อย: ระบบจะแจ้งเตือนในผลลัพธ์ว่าไม่ใช่ใบอ้อย (Notsugarcane)
